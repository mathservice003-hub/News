# SciBrief for Work Prototype

직장인을 위한 기술 트렌드 한글 브리핑 웹 프로토타입입니다.

## 주요 기능
- **직장인 친화적 요약**: 기술 중심이 아닌 비즈니스 및 업무 맥락 중심의 구조화된 요약 제공.
- **분야별 큐레이션**: AI, 로봇, 바이오 분야의 신뢰도 높은 매체(MIT Tech Review, Robot Report, STAT) 기반.
- **고급 UI/UX**: Framer Motion을 활용한 부드러운 전환과 프리미엄 디자인 시스템 적용.

## 요약 구조
1. **한 줄 핵심 요약**
2. **무슨 이야기인가? (맥락)**
3. **왜 지금 중요한가?**
4. **직장인에게 의미하는 것 (Insight)**

## 시작하기
```bash
npm install
npm run dev
```

## 기술 스택
- React + TypeScript
- Vite
- Framer Motion (애니메이션)
- Lucide React (아이콘)
- Vanilla CSS (디자인 시스템)
